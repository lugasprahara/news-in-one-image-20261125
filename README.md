One image that sums up the world news of Wednesday 25 November 2026. A 1024×1024 poster in teal, coral and paper: the day's biggest story — a U.S. jury convicting Huawei on 10 of 12 counts — leads, with ten more stories in panels (Shenzhou-24's launch with the first foreign astronaut, Australia's security pact with Solomon Islands, Ukraine's strikes on Russian ships in two seas, a drone strike on Riyadh's tallest tower, Sarkozy ordered to trial, and more), a dark world map dotted with where each story happened, and twelve further stories as one-line briefs. Every story was checked against the sources named in the poster's footer on the day itself. The artwork is `entry.png`, drawn by `render.py` (Python 3 + Pillow); `main.ts` copies it to `/output/entry.png` byte for byte, and refuses to run if the file is missing or oversized.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
